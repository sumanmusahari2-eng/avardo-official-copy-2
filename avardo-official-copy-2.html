Store settings

Announcement banners

Shown at the top of the homepage. Text banner: type the banner text — the Link is optional and, when set, makes the whole banner tappable. Image banner: paste an image URL (ending in .jpg, .jpeg, .png, .webp or .gif, e.g. from an image host) in the Link field and leave the text empty — the image will show full-width as the banner. If you add text with an image URL, the text is used as the image description and shown as a small caption underneath. A banner with neither text nor an image link shows nothing. Leave the list empty to show no banners.

FAQ questions

Shown in the FAQ & Support section on the homepage. Edit, add or remove questions here.

Highlights

The round circles at the top of the homepage, shown in list order — use the ↑ ↓ arrows to sort them. Image: paste an image URL to show that picture in the circle; leave it empty to show the letter instead. Link: choose what a tap does — open a game's top-up panel, apply a category filter, or go to a custom URL.

Select a game

Pick one game to edit just its details, banner image and pack prices — no scrolling through the whole catalogue. Choose All games to see every editor again. Saving keeps all other games exactly as they are.
